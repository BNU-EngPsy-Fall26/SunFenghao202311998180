# 火线值守 · Ember Watch

一个纯前端、可直接运行的信号检测论（Signal Detection Theory, SDT）交互实验。玩家扮演卫星山火预警值守员，在云层、地表热源和传感器噪声中判断是否存在真实早期火情。

## 直接运行

不需要安装依赖，不需要后端，也不需要联网。

1. 下载或 clone 整个仓库。
2. 双击根目录的 `index.html`。
3. 使用 Chrome、Edge 或 Firefox 的较新版本打开。

如果希望通过本地服务器运行，可在项目目录执行任意静态服务器命令，但这不是必需条件。

## 游戏规则

- 每局固定 30 个试次。
- 每个刺激限时显示 1.5 秒，随后隐藏。
- 按 `F` 或点击“发布火情预警”，表示判断存在真实火点。
- 按 `J` 或点击“判定为环境干扰”，表示判断不存在真实火点。
- 每次判断后立即反馈击中、漏报、误报或正确拒斥，并更新任务得分。
- 可调火情先验概率 P(S) 与系统敏感性 d′。

## 场景参数与四种结果

- **信号 S**：真实的早期山火热异常或烟柱。
- **噪音 N**：云影、薄雾、工业热源、裸岩反光及传感器波动。
- 默认先验概率：`P(S)=0.30`，即 30 次中精确安排 9 次信号试次。

| 结果 | 用户判断 | 实际状态 | 现实含义 |
|---|---|---|---|
| 击中 H | 发布预警 | 有火情 | 及时启动核查与响应 |
| 漏报 M | 判定干扰 | 有火情 | 延误处置，代价最大 |
| 误报 FA | 发布预警 | 无火情 | 占用无人机和复核资源 |
| 正确拒斥 CR | 判定干扰 | 无火情 | 排除干扰，继续监测 |

## SDT 计算

结果页展示原始击中率、误报率和准确率：

```text
P(H)  = H / (H + M)
P(FA) = FA / (FA + CR)
Accuracy = (H + CR) / N
```

为避免原始比率为 0 或 1 时 `z()` 产生无穷值，d′ 与 c 使用 log-linear correction：

```text
Hc  = (H + 0.5) / (H + M + 1)
FAc = (FA + 0.5) / (FA + CR + 1)
d′  = z(Hc) - z(FAc)
c   = -0.5 × [z(Hc) + z(FAc)]
```

结果页同时提供证据分布图、ROC 曲线和可拖动的标准 c 模拟器。多轮结果仅保存在当前浏览器，最多显示最近 5 轮。
