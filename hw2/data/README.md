# 数据管理

网页每次完成主任务判断后自动保存到当前浏览器localStorage（`attention-field-sessions-v1`），可以在研究者入口导出JSON/CSV。备份文件含明确的`mode`：`preview`、`pilot`或`formal`。

- `raw/`：正式平台原始导出、本机原始备份，保留原文件；被Git忽略，不自动公开。
- `pilot/`：预实验与体验备份；被Git忽略，不能作为正式参与者数据。
- `summary/`：2026-11-09固定导出的匿名汇总、质量清单、文件哈希与独立核验结果；不含逐试次原始记录、会话ID或设备信息。

老师平台会重新匿名化编号，因此平台记录与本机记录分别分析，不能简单相加。网页采用相同协议、同一编号、同一范式最早完整会话；主要比较还需满足有效试次数。

最终固定报告在`report/index.html`，同时嵌入网页“研究报告”，使用本地相对路径，直接双击可读。图件与HTML须一起保留；动态数据工具仍可导出其当前自包含HTML。
