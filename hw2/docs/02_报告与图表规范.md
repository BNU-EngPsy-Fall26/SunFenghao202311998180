# 报告与图表规范：沿用既有结项报告的优点

## 本次实际阅读的依据

风格来源：作者既有结项报告的方法、结果与图表规范。本地曾阅读下列材料，只提炼写作和排版规则，不公开原项目目录或私人研究内容。

- 旧报告的图表风格规范：主要视觉规则。
- 正式稿与工作底稿的协作约定：材料分离、按证据链组织。
- 方法与结果正文：方法说明、模式判断、结果与图表衔接，保留未获支持的假设。
- 实际查看过的纵向轨线图与条件比较图：对照规范检查优点和排版问题。

这里只提取通用规范。旧研究的私人数据、图和结果不复制到课程项目，也不提交到GitHub。

## 写作：每个分析回答一个问题

基本顺序：**要检验什么 → 为什么这样比较 → 关键证据 → 可以得出什么判断**。

- 方法只交代读者理解和复现比较所需的信息。
- 正文讲方向、大小、不确定性和结论，不逐行朗读表格。
- 图表放在相邻论证处，正文明确指出要看的比较。
- 每段保留一至两个最重要的数值，完整数据由表承接。
- 路径、运行日志、调试、自动化说明留在工作底稿/README技术部分，不混进正式结果。
- 复现和改进分别回答；原效应出现不代表改进成功，改进有差异也不代表证明了唯一机制。
- 假设未获支持就如实写。非显著不等于完全无效，方向一致不等于已经证明。
- 小样本重点交代个体差异、配对效应与区间，不堆复杂模型和p值。

旧稿有时仍较长并保留实现细节；本作业按用户最新要求进一步压缩。继承证据逻辑，不机械照搬篇幅或旧项目模型。

## 图表：固定视觉系统

- 白底、浅灰主网格、弱装饰、无粗外框，适合打印。
- 同一条件在所有图中颜色固定，并用图例/点形/线型辅助，不能只靠颜色辨认。
- 中文及图内英文数字优先Microsoft YaHei，保证Windows稳定显示。
- 原报告静态图规范优先R + ggplot2；网页实时图可用本地前端绘图，但应匹配同一套视觉规范。
- 图内只放坐标、单位、图例和必要标记；长标题、样本量、分析口径、误差线含义写在图注。
- 正式静态图保存矢量PDF与600dpi PNG；网页同时提供可读的HTML表。无需给课程网站强加R运行依赖。
- 参考字号：轴标题10.5pt，轴刻度/图例9pt，注释8.5pt；网页根据屏幕放大，保持层级。
- 线宽约0.7–0.9、点大小2.0–2.4，CI带透明度0.12–0.18（具体单位按绘图库换算）。

本作业建议映射：

| 含义           | 颜色         | 搜索实验     | 比例判断实验        |
| -------------- | ------------ | ------------ | ------------------- |
| 经典参照条件   | 蓝 `#4E79A7` | 原特征条件   | 原柱图              |
| 待改进的原条件 | 灰 `#7F7F7F` | 原联合条件   | 原饼图              |
| 改进条件       | 橙 `#D95F02` | 颜色空间分区 | 饼图+共同基线对照尺 |

上述是报告配色，与实验刺激配色分开管理。搜索刺激在attention-v1.1中因辨色反馈统一替换为蓝/橙/紫红，具体色值和原文适配差异见README与03文档，不按报告条件色逐条件改变刺激。旧研究“无表露/事实/情感”的含义不迁移到本实验。

## 根据实际旧图补上的质量门槛

- 旧轨线图局部标签重叠、灰色偏浅，配色也与正式规范不同；本作业以规范为准，减少逐点标签并避让。
- 旧柱图有断轴；本作业比较条件均值优先用点区间图或配对散点。若画柱图，数量轴从0开始；不使用没有明确说明的断轴夸大差异。
- 小样本展示每名被试的点或配对线，避免仅用一个均值柱遮住个体差异。
- 区间必须标明SD、SE或95%CI，不能笼统称“误差线”。配对效应区间与各条件均值区间要区分。
- 搜索图：RT–集合大小曲线、个体斜率/斜率差、准确率检查。
- 判断图：条件误差的配对点图，必要时估计值–真实比例图；原文口径的log误差与直观百分点误差区分。
- 模型预测线必须标“模型预测/示意”，与真实数据样式明确区分；收数前不伪造实测图。

## 表格与数值

- 三线表；不设竖线和大面积底纹。
- 表题上方、表注下方。表注明缩写、样本量、单位、缺失与排除口径。
- 文档中文宋体、英文数字Times New Roman；网页提供适合阅读的字体回退。
- 均值标准差：`M (SD)`；人数百分比：`n (%)`；`p = .032`、`p < .001`，不写`p = .000`。
- RT单位ms；搜索斜率ms/item；比例误差单位百分点，不混写为相对百分比。

## 本作业每个实验的报告骨架

**方法（短段）**：任务、条件、自变量/因变量、试次、平衡方法、有效数据和效应定义。

**结果（短段+图）**：先原效应，再改进效应。给实际N、关键差异和区间，结合图指出模式。

**解释（短段）**：支持到哪一步、是否存在速度—准确性代价、与原文有哪些不可直接比较之处。

不在未收数据时填任何结果数值；以后从同一汇总输出生成表、图和正文关键数值，减少三者不一致。
