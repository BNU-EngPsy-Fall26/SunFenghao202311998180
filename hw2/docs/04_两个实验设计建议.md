# 两个实验设计建议：供学生理解与选择

日期：2026-10-28；更新：2026-11-08。状态：用户已确认本方案并验收前端；本文件随收数前版本提交。理论依据见03文档。

## 共同主线

“信息组织能否降低视觉加工成本？”一个实验测找目标的速度，一个实验测读图的精度。两者覆盖W6/W7，任务和指标清楚，能在同一网站完成，又各自保持独立研究问题。

同一批目标5名他人完成两实验；实验内使用被试内设计。可按05文档预定规则扩展至10名。独立招两组人分别做两个范式也可行；原/改进条件间若采用被试间设计，则需要更多人才能得到同样数量的每条件样本，当前不采用。

## 实验一：原特征/联合搜索 + 颜色空间分区

### 参与者做什么

在一屏字母中判断目标是否存在。当前特征条件判断“有紫红色字母或S吗”；原联合条件与改进联合条件判断“有蓝色T吗”。两键回答，按键映射和显示面积固定。2026-11-08体验反馈后统一替换原绿/棕配色，方法偏离见03；同一任务三条件不使用不同的个体配色。

### 三种模式

| 模式                 | 任务      | 布局                   | 作用         |
| -------------------- | --------- | ---------------------- | ------------ |
| feature_original     | 紫红色或S | 橙色T/蓝色X混合分布    | 经典特征参照 |
| conjunction_original | 蓝色T     | 相同干扰项混合分布     | 经典联合条件 |
| conjunction_grouped  | 蓝色T     | 按颜色在空间上聚成区域 | 新增改进条件 |

改进只重组颜色与位置关系：同一试次族保留字母集合、颜色计数、总数量、外接范围和候选位置，改变各颜色如何分布。蓝色T在存在试次替换蓝色候选中的一个字母，不能额外增加项目使目标存在可由数量判断。

蓝色分区左右平衡，目标离心率/位置分层平衡；集合大小1时不可能形成分区，作为基本反应边界保留，不应制造虚假布局差异。集合5、15为奇数时，两颜色计数尽量均衡并在试次间平衡；目标存在与否不能引入系统计数线索。

### 为什么可能有效，为什么也可能无效

分组/子集搜索研究支持观察者可以利用共享特征筛选候选。把相关颜色聚在一起可能降低筛选成本。但原联合条件本来就可按颜色指导搜索，空间分区的额外收益可能较小；分组也可能改变拥挤、局部密度和目标位置分布。即使有效，也只能支持这项布局的表现收益，不能区分所有潜在机制。

### 条件与试次数建议

- 3模式 × 4集合大小（1/5/15/30）× 2目标状态（存在/不存在）× 每格10次 = **240个正式试次/人**。
- 每个分析条件格都有10次。特征存在试次中紫红色/形状目标平衡，作为刺激构成控制，不另当作需要推断的主实验因素。快速体验中两类各2次，仍保留每集合大小存在/不存在各1次。
- 每种模式80次，内部可分两段40次休息。三模式的先后顺序用六种排列近似平衡，不能只依赖小样本随机。
- 每模式先练习；正式数据不混入练习。时长要以试运行估计，不能现在承诺精确几分钟。

### 效应与展示

原效应：目标存在时，联合RT–集合大小斜率减特征斜率。改进效应：原联合斜率减分区联合斜率。二者为正与预测一致；同时报告条件RT和准确率，不能只讲更快。

每名被试先在条件格算正确反应RT，再拟合个人斜率；群体以个人效应为单位汇总。原文精确数值不作为成功判定门槛。

### 备选与权衡

| 方案                 | 优点                                             | 主要代价                                                           | 当前判断 |
| -------------------- | ------------------------------------------------ | ------------------------------------------------------------------ | -------- |
| 颜色空间分区         | 无需提前告知目标位置；相同刺激集合；分组理论依据 | 必须匹配位置/密度，仍有多种机制                                    | 推荐     |
| 目标颜色子集提前提示 | 候选筛选机制直接                                 | 需要等时中性提示；准备时间与刺激后RT分开；原任务已知颜色时可能冗余 | 备用     |
| 无关颜色自动消隐     | 工程收益清楚，容易实现                           | 实际可见集合大小改变，改善较平凡，较难与同集合原条件比较           | 不优先   |

## 实验二：原柱图/饼图判断 + 共同基线对照尺

### 参与者做什么

每屏有五项数值构成的图，最大项标X，待判断项标A，估计“A约为X的百分之几”。注意不是A占全部的百分比。输入0–100的估计，不显示真值。

### 三种模式

| 模式            | 显示                            | 作用         |
| --------------- | ------------------------------- | ------------ |
| bar_original    | 共同基线柱图                    | 经典位置参照 |
| pie_original    | 饼图                            | 经典角度条件 |
| pie_aligned_aid | 同样饼图 + A与X的共同起点对照尺 | 新增改进条件 |

辅助尺只把原图已经编码的两个值用长度重新表达，不显示百分数、数值刻度答案或鼠标量尺。X可统一归一化到固定参照长度，A按A/X缩放；这是提供更易读的表达，属于工程设计支持，并非让纯角度知觉本身被训练得更准。

### 条件与试次数建议

- 3种显示 × 每种20个独立图形 = **60个正式判断/人**；每图只问一个非最大项。
- 值生成遵循原实验关键约束，数据合计100、最小>3、最大<39、值间差>.1。
- 三模式的比率分布与待判断项大小排序匹配；颜色、图面尺寸、标签、输入方式固定。
- 同一人不反复看到完全相同的五值数据，以减少记答案；使用等难度刺激池并在参与者间轮换模式分配。记录dataset_id以便核验。
- 不按大小自动排序；平衡角度起点、A/X位置和相邻性。辅助区在所有模式保留相同版面空间，降低整体布局变化。
- 先练习，再正式，练习反馈可以解释分母；正式不逐题显示真值，避免后续条件受答案训练影响。

### 效应与展示

主误差：`log2(abs(estimate_pct−true_pct)+0.125)`，保留与原文的指标联系。

直观辅助指标：绝对百分点误差、带符号偏差和回答时间。

原效应：饼图减柱图的个人平均log误差。改进效应：原饼图减辅助饼图的个人平均log误差。为正意味着相应比较方向符合预测。

辅助显示可能提高精度但花更多时间，必须同时交代。辅助版接近柱图也不能通过“不显著”就宣称二者等效。

### 备选与权衡

| 方案            | 优点                                               | 主要代价                                                   | 当前判断 |
| --------------- | -------------------------------------------------- | ---------------------------------------------------------- | -------- |
| 共同基线对照尺  | 与原文位置优于角度理论直接衔接；分母一致；任务不变 | 增加冗余显示，不能声称只改善角度加工                       | 推荐     |
| 饼图加¼/½/¾刻度 | 接近老师建议，改动小                               | 刻度参照整圆，但原任务分母是最大项，可能不匹配；需另核文献 | 备用     |
| 直接写数值/答案 | 容易降低误差                                       | 把知觉判断变成读数/计算，失去本实验问题                    | 排除     |

## 被试与平衡的具体建议

- 初始目标5名完整参与者，每个范式至少5名他人的底线不变；最多10名，停止规则见05文档。这不是统计功效保证。
- P01–P05两范式先后顺序3:2；若扩展到P10则为5:5。各自三模式以六排列循环近似平衡；5人无法覆盖全部六排列，报告这一限制及实际顺序。
- 240+60=300个正式试次/人，不含练习。建议允许中途休息，必要时两个实验分两次做；网站用同一匿名编号配对。
- 若试运行负担过高，先考虑减少不承担核心预测的因素；例如缩减集合大小会降低与原研究一致性，必须明确取舍，不能默默改后仍称原方案。
- 正式RT实验优先统一电脑+键盘；手机可用于阅读报告或演示，不把触屏与键盘反应混为同一正式比较。

## 创建项目之前需要固定的决策

1. 接受这两个范式及具体改进，或选择备选。
2. 接受240+60正式试次，或经试运行后修改并记录理由。
3. 采用被试内设计，并确定顺序分配。
4. 接受预测与有效数据规则，再冻结并commit。

以上是科学设计决策，不要求为了创建项目而先占用三个项目名额；确定一个完整方案后创建一个项目即可。
