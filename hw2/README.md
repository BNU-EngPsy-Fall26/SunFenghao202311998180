## 两个实验与四项预测

**视觉搜索（W6）**：依据Treisman与Gelade（1980）Experiment I的比较结构。当前使用橙色T/蓝色X干扰项，比较“紫红色或S”的特征搜索与“蓝色T”的联合搜索。集合大小1、5、15、30；目标存在/不存在各10次；三个模式共240次。新增联合条件按颜色空间分区，与原联合共享坐标、目标位置、字母/颜色计数。

2026-11-08体验反馈发现旧绿/棕配色难以辨认，统一替换为蓝`#0072B2`、橙`#E69F00`、紫红`#882255`，三条件共用；不对个别参与者切换不同配色。开始搜索前展示实际字母样本，由本人确认三色可分辨；不确定时停止搜索，可单独体验图形实验。这是任务适用性自报，不是色觉诊断，也不保证适合所有色觉类型。配色替换属于与原论文的适配差异，不把其效果当作分区收益。新版旧版数据按协议隔离，旧本机记录保留可导出，不继续旧配色会话。

**图形比例判断（W7）**：依据Cleveland与McGill（1984）位置—角度实验。估计指定项A是最大项X的百分之几，比较柱图、饼图与饼图+共同基线对照尺。每模式20次，共60次。三模式匹配目标比率和大小排序，五值数据不完全重复，辅助尺不显示答案数字。

| 比较             | 差值定义；正值符合预测        |
| ---------------- | ----------------------------- |
| S-R 经典搜索效应 | 原联合斜率−原特征斜率         |
| S-I 分区收益     | 原联合斜率−分区联合斜率       |
| G-R 经典图形效应 | 原饼图log误差−原柱图log误差   |
| G-I 对照尺收益   | 原饼图log误差−辅助饼图log误差 |

log误差 = log2(abs(估计百分数−真实百分数)+0.125)。搜索主斜率基于目标存在的个人条件格正确RT均值。群体汇总以人为单位。

- 同一批初始目标5名他人完成两范式，实验内被试内比较；P01–P05两范式顺序3:2。可按预定招募规则扩展至10名，届时顺序5:5；5人不能覆盖全部六种条件排列，需报告限制。
- 搜索有效RT为150–5000ms，每个目标存在格至少8次有效正确反应，整体准确率≥60%。中断不进入正确率分母，超时计错误。
- 图形答案0–100，每题上限30秒，每模式至少16次有效判断；不因误差大删记录。
- 相同编号/协议/范式采用首次完整会话；各比较有效N单独计算。体验/试运行和正式隔离。
- 报告提供个人配对点、均值、被试级bootstrap 95%CI（2500次）。正式N≥5时提供双侧配对符号翻转检验，对四项预定比较作Holm校正；保留假设和小样本局限。
- 平台重新匿名编号，因此与本机数据分别分析，不能简单相加。
- 检查速度—准确性、精度—时间权衡；未显著不代表等效，也不代表没有效应。

完整[文献核查](docs/03_文献与原范式核查.md)、[设计说明](docs/04_两个实验设计建议.md)、[收数前预测](docs/05_收数前预测草案.md)。浏览器版减少原研究练习与题量、使用不同设备、图形每图只问一个指定项，不宣称完全逐项复刻。
